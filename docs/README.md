# Documentação complementar

Esta pasta reúne materiais de consulta que complementam as aulas e os exercícios do projeto. O objetivo é esclarecer aspectos da linguagem C e apresentar padrões que ajudam a escrever códigos mais organizados e legíveis.

## Documentos disponíveis

| Documento                              | Descrição                                                                                              |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [Sintaxe da linguagem C](sintaxe.md)   | Apresenta a estrutura dos programas em C, os principais símbolos e as diferenças em relação ao Python. |
| [Convenções de escrita](convencoes.md) | Reúne padrões de nomeação, indentação, organização do código e outras convenções adotadas no projeto.  |

## Como utilizar

Os documentos podem ser consultados independentemente das aulas, sempre que surgir alguma dúvida durante os estudos ou o desenvolvimento de um programa.

- Consulte **Sintaxe da linguagem C** para entender como escrever e organizar as estruturas da linguagem.
- Consulte **Convenções de escrita** para conhecer os padrões utilizados nos exemplos do repositório.

Esta documentação será ampliada conforme novos conteúdos e necessidades forem surgindo.
